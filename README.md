# 5 букв

Консольная игра в духе Wordle. Программа загадывает слово из пяти русских букв,
а игрок должен угадать его за шесть попыток.

После каждой принятой попытки программа отмечает каждую букву:

- ✅ - буква стоит на своем месте.
- 🟡 - буква есть в ответе, но стоит в другом месте.
- ❌ - неиспользованной такой буквы в ответе нет.

Пример:

```text
Загадано:  озеро
Ввод:      арбуз
Результат: ❌🟡❌❌🟡
```

## Быстрый старт

```bash
make install # зависимости
make build   # сборка
make run     # запуск
```
Флаги:
```text
--seed N               seed для воспроизводимого выбора слова (по умолчанию - текущее время)
--level УРОВЕНЬ        уровень сложности: easy, medium, hard (по умолчанию - любой)
--category             категория слов: animals, nature, food, home, city, study, sport (по умолчанию - любая)
--color                цветной вывод
--replay               повтор партии без ввода: введите ваши попытки через запятую; нужны тот же --seed (и --level, --category), что были в партии
-h, --help             эта справка
```

## Как играть

После запуска открывается меню:

```text
Меню:
1 - новая игра
2 - выход
3 - статистика 
Выберите пункт:
```

- `1` - новая партия, `2` - выход из программы, `3` - статистика за текущий запуск
- при вводе неизвестного пункта меню выводится подсказка, программа продолжает работу
- после окончания партии программа возвращается в меню, можно играть несколько игр без перезапуска
- после каждой принятой попытки выводится вся история попыток и количество оставшихся попыток
- отклоненная попытка не расходует ход, выводится причина: слово не из пяти русских букв или его нет в словаре

## Словарь и воспроизводимость

Встроенный словарь содержит 85 уникальных слов из пяти русских букв. 
Входной словарь копируется, нормализуется (нижний регистр, обрезка пробелов, `ё` преобразуется в `е`) и проверяется: пустой словарь, слово неверной длины, латиница, цифры, спецсимволы и дубликаты дают ошибку.

Ответ выбирается локальным генератором из seed.

## Правила проверки попытки

Попытка нормализуется так же, как слова словаря функцией checkWord: обрезаются пробелы, регистр приводится к нижнему, ё заменяется на е.
Некорректная попытка возвращает ошибку, не расходует ход и не меняет сессию.

Полное совпадение переводит партию в статус WIN, последняя неверная попытка в LOSE. 
Завершенная партия новых попыток не принимает, ввод слов после проигрыша обрабатывается и отлавливается ошибка.

## Дополнительные задания

| Бонус | Как пользоваться |
| ----- | ---------------- |
| Уровни сложности | `--level easy`, `medium` или `hard`. У каждого уровня свой набор загадываемых слов |
| Категории слов | `--category animals`, `nature`, `food`, `home`, `city`, `study` или `sport` |
| Подсказка | во время партии введите `?` вместо слова. Попытка не тратится |
| Статистика за запуск | пункт меню `3`. Также печатается при выходе, если была сыграна хотя бы одна партия |
| Цветной вывод | `--color`. Буквы слова раскрашиваются по отметкам, победа - зеленым, поражение - красным |
| Replay | `--seed N --replay слово1,слово2,...` - повтор партии без интерактивного ввода |

Примеры:

```bash
make run ARGS="--seed 42 --level easy --category nature"
make run ARGS="--color"
make run ARGS="--seed 42 --replay арбуз,озеро"
```

Каждое слово встроенного словаря (`internal/domain/words.go`) имеет уровень, категорию и подсказку.
Уровень и категория ограничивают только загадываемое слово. 
Попыткой по-прежнему можно ввести любое слово словаря. Для этого добавлена `StartGameWithPool(dictionary, answerPool, maxAttempts, seed)`.
`StartGame` вызывает ее с `answerPool = dictionary`, поэтому поведение базовой игры не изменилось.
Без `--level` и `--category` при том же seed загадывается то же слово, что и раньше.

Для replay номер seed каждой партии печатается при ее старте: `Сессия №2 (seed 43, ...)`.
Передайте этот seed и те же `--level` / `--category`, что были в игре.
